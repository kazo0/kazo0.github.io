{%- comment -%} Self-hosted video sized to the article column. Named `local-video` so it doesn't clash with the theme's `video.html` (the YouTube/Vimeo embed include). Fullscreen comes from the browser's own video controls. Usage: {% include local-video.html src="/assets/images/my-post/demo.mp4" poster="/assets/images/my-post/poster.png" caption="Optional caption" %} Options: src (required), poster, caption, type (default video/mp4), autoplay (default true — set to "false" for a click-to-play video), class (extra classes on the figure, e.g. "width-half" for a phone recording that would otherwise stretch across the whole column — it goes on the figure because .video-figure__video already sets width on the video itself). {%- endcomment -%} {%- assign autoplay = include.autoplay | default: "true" -%}
